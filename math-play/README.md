# MATH CLUB

파스텔·스티커·대형 타이포그래피 스타일을 적용한 로컬 수학게임 포털입니다. 외부 서비스, 설치 패키지, 로그인 없이 작동합니다. 원본 전용 폰트 대신 시스템 글꼴을 사용합니다.

## 공개 배포와 검증

`npm run build` 또는 상위 폴더에서 `node build-public.cjs math-play`를 실행하고 출력된 정적 릴리스 폴더만 배포합니다. `node check.cjs` 또는 `npm test`로 합성 문제를 검증합니다. 설치는 필요하지 않습니다. 공개 호스팅 설정과 미확인 항목은 [공개 배포 안내](../PUBLIC-DEPLOYMENT.md)를 확인하세요. `start.cmd`는 로컬 확인용입니다.

## 실행

Windows에서 `start.cmd`를 실행하고 http://127.0.0.1:4180 으로 접속하세요. 종료하려면 실행 창에서 Ctrl+C를 누르세요. Node.js가 필요하며, 현재 PC에서는 Codex 번들 런타임을 자동 사용합니다. `dist/index.html`을 브라우저로 직접 열어도 플레이할 수 있습니다.

## 기능

- 암산, 수열, 동치 분수, 대소 비교의 4개 게임
- 쉬움/어려움, 주제 필터, 무작위 게임 선택
- 매번 새로 생성하는 10문제, 정오답 안내, 결과 및 재도전
- 브라우저 localStorage에 완료 횟수·최고 점수·누적 정답 저장
- 모바일 레이아웃, 키보드 조작, 감소된 모션 설정 지원

서버는 이 PC의 127.0.0.1에만 바인딩합니다. 공개 배포나 외부 서버로의 전송은 없습니다. 게임 도중 닫으면 진행 중 기록은 저장되지 않으며, 10문제를 완료해야 반영됩니다.
