# 수학 놀이터 — 3단계

초등 수학 허브와 구구단 학습의 최소 흐름입니다. 기존 math-play는 수정하지 않았습니다.

## 실행
1. Windows에서 이 폴더의 `start.cmd`를 실행합니다.
2. 브라우저에서 http://127.0.0.1:4190 을 엽니다.
3. 종료하려면 실행 창에서 Ctrl+C를 누릅니다.

Node.js가 필요합니다. 현재 PC에서는 Codex 번들 런타임을 자동 사용하며 다른 PC에서는 설치된 node 명령을 사용합니다. JavaScript 모듈을 사용하므로 HTML 파일을 직접 더블클릭하는 대신 위 서버로 접속하세요. 서버는 이 PC의 127.0.0.1에만 연결됩니다. 실제 학생 태블릿에 주소를 제공하는 배포는 아직 하지 않았습니다.

## 구현 범위
- 앱 목록에서 카드 생성 → 구구단 진입
- 2~9개씩, 1~9묶음의 그림과 곱셈식
- 한 단 9문제 / 여러 단 10문제 설정, 무작위 문제·보기 4개, 오답 그림 힌트와 재도전
- 첫 응답 기준 점수·다시 볼 문제·다시 시작
- 파스텔·검은 윤곽·둥근 버튼, 텍스트 피드백·키보드 초점
- 학습 기록 영구 저장·로그인·외부 API 없음

3단계까지 구현했습니다. 한 단은 ×1~×9를 각 한 번, 여러 단은 두 단 이상 선택해 모든 선택 단을 포함한 10문제를 중복 없이 냅니다. 보기와 정답 위치도 매번 섞습니다. 다시 연습하기는 점수를 초기화하고 설정 화면으로 돌아갑니다. 디자인·키보드·화면 크기 검증을 진행했습니다. 실물 태블릿 검증은 남아 있고, 확장성·전체 점검은 4단계입니다.

## 파일
- dist/apps.js: 앱 목록(id/title/description/href)
- dist/hub.js: 목록으로 허브 카드 생성
- dist/multiplication/app.js: 학습·연습·결과 화면
- dist/multiplication/model.js: 그림 개수·첫 시도 채점
- dist/style.css: 공통 디자인
- tests/model.test.js: 핵심 로직 테스트

새 앱은 dist 아래에 파일을 만들고 apps.js에 제목·설명·진입 주소를 추가합니다.

## 검증 기록 — 2026-10-17
- Node 테스트 4개 통과: 묶음 범위·총수, 최초 정답, 반복 오답 후 정답, 새 회차·잘못된 보기 거부.
- 브라우저 확인: 허브→학습 이동, 3개씩 4묶음·3×4=12 일치, 고정 문제 표시, 오답 힌트, 재도전 후 0/1 유지·복습 문제 표시, 다시 시작 시 2개씩 1묶음 초기화.
- 실제 학교 태블릿·브라우저별 호환성, 지정 해상도 전체·200% 확대·대비 수치·화면 읽기 도구는 미검증.
- 소스에 학습 저장·외부 요청 코드를 넣지 않았으며 운영 환경 네트워크 점검은 후속 단계에서 수행합니다.

가정: 프로젝트명은 수학 놀이터, 초깃값은 2개씩 1묶음, 맛보기는 3×4, 상태는 탭 메모리에만 유지합니다. 원본 DESIGN.md는 수정하지 않았습니다.

## 2단계 검증 기록
- 자동 테스트 11개 통과: 모든 단·복수 단 조합 생성, 보기 유일성·범위, 첫 시도 점수 불변, 다음 연타·잘못된 설정 차단, 복습 목록·초기화.
- 브라우저: 3단 9문제 완주(×1~×9 중복 없음), 첫 문제 오답→재도전 후 8/9·복습 1개 확인.
- 브라우저: 3·9단 혼합 10문제 완주(중복 없음), 10/10·복습 없음 확인.
- 여러 단 하나만 선택 시 시작 비활성화 확인. 실제 학교 태블릿은 미검증.


## 3단계 사용법
학습 화면 상단의 ‘교실 크게 보기’를 누르면 제목·문제·보기·그림이 함께 커집니다. 다시 누르면 일반 보기로 돌아갑니다. 태블릿에서는 일반 보기를 기본으로 사용하세요. Tab으로 조작 대상을 이동하고 Enter/Space로 선택할 수 있습니다. 단 선택 라디오는 방향키로 이동합니다.

화면별 검증 결과와 미검증 항목은 [ACCESSIBILITY-QA.md](ACCESSIBILITY-QA.md)를 확인하세요. 기록의 1·2단계 검증은 당시 결과이며, 현재 동작은 3단계 기준입니다.


## PDF 글자 수 세기 — 2026-10-17
허브에 PDF 도구를 추가했습니다. start.cmd 실행 후 허브에서 ‘PDF 글자 수 세기’를 선택하세요. 이미 서버를 실행 중이었다면 종료 후 다시 실행해야 새 .mjs MIME 설정이 적용됩니다.

- PDF 선택·드래그 앤 드롭, 공백 포함/제외 글자 수, 전체/페이지별 결과, 추출 텍스트, 초기화, 암호 입력, 진행률을 제공합니다.
- 최대 100MB의 PDF 1개를 처리합니다. 스캔 이미지는 OCR하지 않으며 텍스트 없는 페이지를 안내합니다.
- 글자 수는 NFC 정규화 후 Intl.Segmenter의 글자 묶음 기준입니다. 줄바꿈은 제외하고, 공백 제외에는 모든 Unicode 공백을 제거합니다. PDF 배치에서 복원한 띄어쓰기는 원본 편집기와 다를 수 있습니다.
- PDF와 결과는 브라우저 메모리에서만 처리합니다. 업로드 API, DB, 브라우저 저장소, 분석/추적 기능이 없습니다. 초기화·페이지 이탈 시 화면 및 작업을 정리합니다.
- PDF.js 5.3.93과 워커·CMap·폰트·WASM을 dist/pdf-counter/vendor에 포함했습니다. CDN이 필요하지 않습니다. 라이선스는 vendor/LICENSE입니다. 최신 Chrome/Edge 사용을 권장합니다.
- 로컬 서버는 127.0.0.1에만 연결되고 GET/HEAD만 허용합니다. PDF 페이지의 CSP는 외부 연결 및 폼 전송을 제한합니다. 정적 프로그램 파일 요청은 로컬 서버에서 읽고, 선택한 PDF의 내용은 서버에 전달하지 않습니다.
- 검증: 기존 학습 테스트 11개, 글자 수/조각 복원/실제 PDF 바이트 추출 테스트 3개 통과. JS 문법과 모듈의 HTTP 200·JavaScript MIME 확인. 자동 브라우저의 로컬 연결이 시간 초과되어 화면·파일 선택·암호·초기화의 브라우저 종합 검증은 미완료입니다.

## 알파벳 짝꿍 찾기 — 2026-10-17
허브의 ‘알파벳 짝꿍 찾기’ 카드에서 실행합니다. A–Z 중 무작위 6쌍을 양쪽에서 선택하며, 오답은 다시 고를 수 있습니다. 찾은 짝·도전 횟수·완성 안내와 새 게임을 제공합니다. 시간 제한·로그인·영구 저장·외부 요청은 없습니다. 키보드 조작과 좁은 화면 배치를 지원합니다. 자동 검증: 생성·오답·양방향 매칭·완성·초기화 및 기존 테스트 통과. 실제 브라우저 화면과 태블릿 검증은 미완료입니다.
