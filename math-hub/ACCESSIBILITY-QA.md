# 3단계 디자인·접근성 검증 기록

검증일: 2026-10-17. 대상: 로컬 math-hub. 실제 학교 기기 시험이나 접근성 인증을 의미하지 않는다.

## 변경
- 교실 크게 보기: 문제 최대 88px, 제목 최대 72px, 답 보기 48px·높이 112px. 좁은 화면에서는 자동 조정. 해당 설정은 저장하지 않는다.
- 일반 태블릿: 답 보기 36px·높이 96px, 두 열 배치. 600px 이하에서는 글자 32px·높이 80px.
- 묶음 그림: CSS 그리드로 묶음 경계 유지, 9×9의 81개도 묶음별로 줄바꿈. 장식은 허브에 집중.
- 본문 건너뛰기 링크, 최소 52px 버튼·선택 상자, 라벨 전체 터치 영역, 명확한 키보드 초점.
- 그림은 '9개씩 9묶음 그림'처럼 이름이 있는 이미지 역할로 제공. 장식 동그라미를 개별 낭독하지 않는다. 힌트 설명에는 정답 합계를 넣지 않는다.
- 정답/오답은 글·기호로 안내. 정답 후 다음 버튼은 피드백을 설명으로 참조한다. 화면 전환 때 제목으로 초점 이동.
- 움직임 감소·고대비 모드 CSS 대응. 학습 초기 로딩에 안내 문구 제공.

## 화면 검증
인앱 브라우저에서 실제 innerWidth/innerHeight를 읽어 CSS 픽셀 단위를 확인했다. 도구의 물리 픽셀 배율 1.5를 보정해 아래 크기로 확인했다.

| 환경 | 확인 화면·상태 | 결과 |
|---|---|---|
| 768×1024 | 허브, 9×9 익히기, 설정, 오답 힌트, 연습, 결과 | 가로 넘침 없음 |
| 1024×768 | 동일 | 가로 넘침 없음 |
| 1920×1080 | 동일 | 가로 넘침 없음 |
| 384×512 | 동일, 일반·교실 크게 보기 | 가로 넘침 없음, 세로 스크롤로 접근 |
| 320×512 | 9×9 익히기, 설정, 일반 문제 보기 | 가로 넘침 없음 |

9×9 학습의 DOM과 화면에서 묶음 9개·동그라미 81개 확인. select 80×52 CSS px. 지정 세 화면에서 일반 보기 버튼 높이 96px, 교실 크게 보기 버튼 높이 112px 확인. 설정 라벨·버튼은 48px 미만 없음. 고정 높이·가려진 오버플로로 내용을 자르지 않는다.

## 키보드·의미 구조
- Tab → 건너뛰기 링크 표시 → Enter → main으로 초점 이동 확인.
- 라디오 ArrowLeft로 9단→8단 변경, 선택 상태·초점 일치 확인.
- Enter로 연습 시작·보기 선택·다음·결과 이동, 9문제 완주 확인.
- 오답 뒤 같은 보기에서 초점 유지, 정답 뒤 next 버튼으로 이동·aria-describedby=feedback 확인.
- 결과에서 H1으로 초점 이동, 첫 오답 1개를 반영한 8/9·복습 1개 확인.
- Space로 여러 단 모드·체크박스 선택. 한 단만 선택했을 때 시작 비활성, 두 단이면 활성 확인.
- role=status, aria-live, 이미지 이름, form label 연결은 DOM·접근성 트리에서 확인했다. 실제 음성 출력은 미검증.

## 색상 대비
상대 휘도 공식으로 계산. 일반 텍스트 목표 4.5:1 이상, 초점 표시 목표 3:1 이상.

| 전경 / 배경 | 비율 |
|---|---|
| 검정 / 흰색 | 21.00:1 |
| 검정 / 하늘색 #dceeff | 17.72:1 |
| 검정 / 연보라 #e9ccff | 14.55:1 |
| 흰색 / 검정 주버튼 | 21.00:1 |
| #555555 / #e9e9e9 비활성 버튼 | 6.14:1 |
| #5c4ade 초점 / 흰색 | 6.02:1 |
| #5c4ade 초점 / 하늘색 | 5.08:1 |

결과 화면의 표시된 텍스트 DOM 스타일을 따로 확인했으며 최소 14.55:1, 4.5 미만 없음. 이 검증은 모든 동적 상태를 자동 감사한 결과는 아니다.

## 기능 회귀 확인
기존 모델 테스트 11개 통과. 문제 생성·채점·오답 재도전 로직 변경 없음. 화면 스크립트 문법 검사 통과.

## 검증 한계·실기기 확인 항목
- 실제 200% 브라우저 확대 단축키는 이 도구에서 확대율을 변경하지 않았다. 대신 768px 화면을 절반 폭 384px로 줄여 재배치 확인. 실제 200% 확대의 렌더링·입력은 미검증이다.
- iPad Safari·Android 태블릿의 실제 터치, 교실 화면 거리·조명·프로젝터 대비는 미검증.
- 화면 읽기 도구의 실제 읽기 순서·음성, OS 고대비 모드 출력은 미검증. 의미 구조와 CSS 대응만 확인했다.
- 실사용 전 태블릿에서 200% 확대, 오답 힌트의 스크롤, 교실 맨 뒷자리에서 숫자 가독성을 확인한다.
