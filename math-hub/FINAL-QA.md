## 구구단 비저장 점검
원본 앱의 동작을 바꾸지 않고 저장소·자원 목록을 읽는 임시 qa-audit.js와 버튼을 사용했다. 진단은 저장소에 값을 쓰거나 삭제하지 않았으며 점검 후 HTML의 스크립트 연결과 파일을 제거했다.

| 항목 | 학습 전 | 단일 단 9문제 후 | 혼합 10문제 후 |
|---|---|---|---|
| localStorage 키 | 없음 | 없음 | 없음 |
| sessionStorage 키 | 없음 | 없음 | 없음 |
| document.cookie | 빈 문자열 | 빈 문자열 | 빈 문자열 |
| IndexedDB 목록 | 없음 | 없음 | 없음 |
| Cache Storage 목록 | 없음 | 없음 | 없음 |
| 서비스워커 등록 | 없음 | 없음 | 없음 |
| URL | /multiplication/index.html | 동일 | 동일 |
| Resource Timing 자원 | CSS·학습 스크립트·모델·임시 진단 스크립트 | 동일 | 동일 |

자원 요청은 모두 127.0.0.1의 정적 프로그램 파일이었다. 답·점수 전송이나 학습 중 신규 자원 요청은 관찰되지 않았다. Resource Timing은 모든 네트워크 채널의 패킷 감사를 대신하지 않으므로 학습 소스도 검색하여 fetch/XMLHttpRequest/sendBeacon/WebSocket/저장 API 호출이 없음을 확인했다. 일기는 명시적 저장 요청에만 로컬 API와 DB를 사용한다. 브라우저 자체 방문 기록·OS 메모리·사용자가 찍은 화면까지 지우는 기능은 아니다.

## 이탈 처리
기존 네이티브 confirm은 자동화 도구가 대화상자에서 응답하지 않아 재현 검증을 완료하지 못했다. 이를 페이지 내 dialog로 교체했다. 최종 브라우저 확인: 기본 초점 ‘계속 풀기’, 취소 시 같은 문제 유지, ‘돌아가기’ 시 설정 복귀. 초기 자동화 정지는 최종 앱 동작 실패로 집계하지 않으며 교체 사실을 기록한다.

## 자동 테스트
총 21개 통과: 구구단 11개, 앱 목록 3개, 알파벳 1개, PDF 3개, 일기 3개.
- 앱 목록: 필수 네 필드, 빈 목록, 중복 ID·잘못된 주소 거부, 모든 실제 진입 파일 존재.
- 일기: 입력·날짜 검증, 생성·조회·수정·삭제, 버전 충돌 거부, SQLite 종료·재열기 유지, HTTP 요청 출처 검사·DB 파일 비공개.
- 실제 개인 자료 대신 합성 데이터와 임시 폴더를 사용한다. 테스트용 DB를 사용자의 기본 DB에 복사하지 않았다.
- PDF.js 테스트에는 Node에서 legacy 빌드 권장 경고가 나오지만 테스트는 통과했다. PDF 앱의 파일 선택·암호·종합 UI를 이 결과로 검증 완료라고 보지 않는다.

## 일기 브라우저 검증
별도 포트 4191과 별도 임시 DB 사용. 허브 카드 연결, 일기 작성·저장, 새로고침 후 목록 유지·재열기, 제목 수정·저장, 저장하지 않은 초안 이탈 취소·확인, 일기 삭제 확인 후 목록 0편을 확인했다. 768×1024, 1024×768, 1920×1080, 384×512에서 가로 넘침 없음. 이 결과는 실제 iPad/Android 터치 검증을 대신하지 않는다.

기본 로컬 DB는 %LOCALAPPDATA%\MathHub\diary-data\diary.sqlite에 스키마를 준비했다. 기본 경로는 OneDrive 작업 폴더 밖이다. 일기 데이터는 외부 서비스로 보내지 않으며 브라우저 저장소 대신 로컬 SQLite를 사용한다. 요청 출처·JSON 전용 변경 요청을 검사하고 서버는 루프백에만 바인딩한다. 일기 암호화·회원 구분·원격 접속은 구현하지 않았다.

## 최종 제한과 운영 인계
- 본인이 실행한 이전 4190 서버를 종료하고 start.cmd를 재실행해야 새 일기 API가 적용된다. 기존 사용자 서버 프로세스는 임의로 종료하지 않았다.
- 로컬 127.0.0.1 주소는 다른 태블릿에서 이 PC에 접속하는 주소가 아니다. 배포·도메인·기관 접속 승인은 별도다.
- 실제 200% 확대, 화면 읽기 음성, 실제 학교 태블릿·교실 조명과 거리 점검은 남아 있다.
- 알파벳·PDF 앱은 기존 소스를 보존하고 자동 회귀 시험에 포함했다. 모든 추가 앱의 브라우저 기능을 새로 완전 검증하지는 않았다.
- 설명서: USER-GUIDE.md. 앱 추가법·로컬 실행·저장 경로·백업·오류 처리 포함. 실제 사용자 DB 백업·복원은 실행하지 않았다.
