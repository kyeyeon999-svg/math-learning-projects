# 수학 놀이터

## 공개 배포

공개 버전에서는 일기 기능을 제외합니다. `npm run build` 또는 상위 폴더에서 `node build-public.cjs math-hub`를 실행하고 출력된 정적 릴리스 폴더만 배포하세요. 기존 dist와 로컬 서버를 그대로 공개하지 마세요. 설치는 필요하지 않습니다. 환경설정·파일 제외·검증 명령과 미확인 항목은 [공개 배포 안내](../PUBLIC-DEPLOYMENT.md)를 따릅니다. 아래 일기 설명은 로컬 전용입니다.

교육용 앱 허브와 구구단 학습의 1~4단계를 구현하고, 로컬 SQLite에 저장하는 일기장을 추가했습니다.

## 실행
1. 실행 중인 기존 서버 창이 있으면 Ctrl+C로 종료합니다. 일기 API가 추가되어 서버 재시작이 필요합니다.
2. `start.cmd`를 실행합니다.
3. http://127.0.0.1:4190 을 엽니다. 페이지가 예전 모습이면 새로고침합니다.
4. 종료는 서버 창에서 Ctrl+C입니다.

HTML을 직접 더블클릭하지 마세요. 일기장은 함께 실행되는 로컬 서버가 필요합니다. 현재 PC의 Codex 번들 Node.js를 자동 사용하고, 다른 PC에서는 node:sqlite를 지원하는 Node.js 24 이상이 필요합니다. 별도 패키지 설치는 없습니다.

## 앱과 데이터
| 앱 | 주요 기능 | 데이터 저장 |
|---|---|---|
| 구구단 | 묶음 그림, 한 단 9문제·여러 단 10문제, 힌트·재도전·첫 시도 채점 | 저장 안 함 |
| 나의 일기장 | 날짜·제목·내용, 목록·검색·수정·삭제 | 이 컴퓨터의 SQLite 파일 |
| 알파벳 짝꿍 찾기 | 대문자·소문자 6쌍 연결 | 영구 저장 안 함 |
| PDF 글자 수 세기 | 로컬 PDF 텍스트 추출, 공백 포함·제외·페이지별 집계 | 선택 PDF·결과 업로드 및 영구 저장 안 함 |

일기 DB 기본 위치: `%LOCALAPPDATA%\MathHub\diary-data\diary.sqlite`.
현재 PC: `%LOCALAPPDATA%\MathHub\diary-data\diary.sqlite`.
OneDrive 작업 폴더와 분리했습니다. 테스트는 별도 임시 DB를 사용했으며 사용자 DB에 검증용 일기를 넣지 않았습니다. DIARY_DATA_DIR 환경변수로 다른 로컬 폴더를 지정할 수 있습니다.

앱은 127.0.0.1에만 연결됩니다. 현재 주소를 다른 태블릿에 입력해도 이 PC의 일기나 앱에 연결되지 않습니다. 실제 교실 배포는 별도 작업입니다. 일기는 암호화·계정 구분이 없어 이 Windows 계정과 파일에 접근할 수 있는 사람은 내용을 볼 수 있습니다.

## 개발·검증
`check.cmd`를 실행하면 모델·앱 목록·SQLite·로컬 HTTP 테스트를 실행합니다. Node가 PATH에 있다면 `npm test`도 가능합니다. 2026-10-17 감사 실행은 21개 중 20개 통과, HTTP 1개는 로컬 접속 EACCES로 미확인입니다. HTTP 테스트는 실제 사용자 DB 대신 임시 폴더·빈 포트의 로컬 서버를 사용하고 종료 후 정리합니다. HTTP를 제외한 검증은 `npm run test:offline`이며 전체 테스트 통과를 의미하지 않습니다.

- `dist/apps.js`: 새 앱 등록
- `dist/registry.js`: 중복 ID·내부 진입 주소 검증
- `dist/hub.js`: 카드 생성
- `dist/multiplication/`: 학습 화면·문제·채점
- `dist/diary/`: 일기 화면
- `diary-store.cjs`: SQLite 자료·입력·수정 충돌 검사
- `server.cjs`: 정적 파일 및 일기 전용 로컬 API

구구단에는 저장 API 호출을 추가하지 않았습니다. 일기만 서버 저장을 사용합니다. 실제 학교 태블릿, 200% 브라우저 확대, 화면 읽기 음성 출력, PDF 파일 선택·암호 등 모든 부가 앱의 실기기 종합 검증은 남아 있습니다.
